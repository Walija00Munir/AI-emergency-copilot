# 🚨 Universal Emergency AI Co-Pilot

A high-speed AI orchestrator designed to provide instant, structured guidance for any crisis—from medical emergencies to technical disasters.

## 🛠️ Features
- **Generalist AI Brain:** Uses Gemini 2.0 Flash to categorize and solve diverse problems.
- **Secure Architecture:** Zero-exposure API key management via `.env`.
- **Responsive Dashboard:** Real-time feedback with severity levels and action steps.

## 🚀 Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Add your API Key to a `.env` file: `GEMINI_API_KEY=your_key_here`
3. Start the server: `python app.py`
4. Open `index.html` in your browser.

## 🛡️ Security
This project uses `.gitignore` to ensure sensitive credentials never leak to version control.
